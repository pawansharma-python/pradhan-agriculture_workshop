## About the Project

**Pradhan Agriculture Workshop** is a business-focused website for agriculture machinery and farm equipment. The project presents a clean product catalog, a secure seller login flow, an EMI calculator, inquiry cart functionality, and a CRM-style lead management section for follow-ups.

This project was designed with a strong brand identity using a green and brown theme that matches the agriculture domain.

## Features

- Clean and professional landing page
- Product catalog with search, category filter, and sorting
- Product cards with pricing, badges, and quick actions
- Inquiry cart / purchase list for selected products
- EMI calculator for estimating monthly installments
- Seller login page for secure portal access
- Seller dashboard for adding catalog items
- Lead management / CRM-style follow-up section
- WhatsApp-based contact and inquiry flow
- Footer with contact details and social links
- Fully responsive layout for desktop and mobile devices

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive UI Design
